# Xeffic Better CMS

This upgrade keeps the current website design and adds a more powerful Pages CMS setup.

You can now edit:
- all page headings and paragraphs already connected to CMS
- SEO title, description and social sharing image per page
- section images and optional section background images
- primary and secondary button text and links
- card text, links and individual card images
- step / metric / item text and images
- multiple gallery images per section
- header and footer logos
- contact emails and LinkedIn URL
- optional navigation override
- optional footer link override
- optional theme colours
- hide/show existing sections, cards and items

Important: this CMS can change the content and images of the existing layout. Creating a completely new page layout or new type of section still requires a code/template change.
