# Xeffic Website v3

This version intentionally follows the reference site's visual structure much more closely:
- large top-left hero card
- compact top-right service card
- three pastel service cards along the bottom
- bold black/blue typography
- floating information cards
- rounded light-gradient panels
- handwritten-style annotations
- responsive mobile layout

The visuals and copy are original to Xeffic.

## Upload
Upload ALL files in this folder into the root of the existing GitHub `xeffic-website` repository and replace the old files.

`styles.css` and `main.js` remain in the root to avoid the earlier missing-assets problem.
